# Ocean Above the Clouds

A colossal whale breaches through an ocean that hangs above a sea of clouds at sunset, with a tiny human on a cliff for scale.

Entry for the [make.fun ai-excited-01 bounty](https://make.fun/bounty/ai-excited-01). Referral code: **p8atzycs**.

Run `node main.ts` with Node.js 22.18 or later. Set `MAKEFUN_OUTPUT_DIR` to choose the output directory (default: `/output`). The program copies `entry.jpg` byte for byte to `entry.png`; the image remains JPEG encoded.
