# ai-excited-01

A colossal whale breaches through an ocean that hangs above a sea of clouds at sunset, with a tiny human on a cliff for scale.

Bounty: [make.fun ai-excited-01](https://make.fun/bounty/ai-excited-01)

Referral code: `p8atzycs`

## Run

With Node.js 22, run:

```sh
node main.ts
```

Set `MAKEFUN_OUTPUT_DIR` to choose the output directory (default: `/output`):

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

The program copies `entry.jpg` byte for byte to `entry.png`. The image remains JPEG encoded despite the output filename.
